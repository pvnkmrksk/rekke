REKKE — INSTALLATION

MAC
1. Open the DMG. Drag Rekke.app onto the Applications shortcut.
2. Eject the image and open Rekke from Applications. Allow camera access.
3. Only the app needs copying. Its resources are contained inside the bundle.
   Configs, marker state and saved backgrounds are writable under:
   ~/Library/Application Support/Rekke/configs/

ONE-TIME TERMINAL SHORTCUT FOR A TRUSTED DOWNLOAD

    xattr -dr com.apple.quarantine "/Applications/Rekke.app"

Then open the app normally. Adapt the path if installed elsewhere. This clears
quarantine only on Rekke.app; it does not disable Gatekeeper globally or sign/
notarize the app. No sudo is normally needed for an app you own. Repeat for a
new downloaded release if needed. Camera permission is separate.

Rekke is free software with an ad-hoc signature but no paid Apple Developer ID
signature or notarization. Approve only a release whose origin you trust.
Alternatively, try opening once, then System Settings > Privacy & Security >
Open Anyway. On macOS 14 or earlier, right-click > Open can also work; Apple
removed that override in macOS 15. A malware/damage alert is a different issue.
https://support.apple.com/en-au/102445
https://developer.apple.com/forums/thread/739357

WINDOWS 10/11 X64
Run Rekke-0.5.1-windows-x64-setup.exe. The installer uses your user account,
adds desktop/Start-menu shortcuts and needs no administrator elevation.
Config state is under %APPDATA%\Rekke\configs and survives uninstall.
This unsigned build can show SmartScreen. Verify the download's origin.

UBUNTU 22.04+ X86-64
    sudo apt install ./rekke_0.5.1_amd64.deb
Open Rekke from the Science/app menu or run: rekke
Configs live under ~/.config/rekke/configs (or XDG_CONFIG_HOME/rekke/configs).

MULTIPLE RIGS
Edit each seeded camera config and rigs.toml for your devices and unique ports.
Close any instance already using those ports, then run:
    rekke --rigs
    rekke --rigs --headless --record
On Mac replace rekke with /Applications/Rekke.app/Contents/MacOS/rekke.
Explicit --config and --rigs paths also work. Ctrl+C stops the rig set cleanly.

PORTABLE PACKAGES
Extract the whole folder. Run ./rekke (rekke.exe on Windows), or a launcher.
Portable CLI configs resolve beside the executable; the Mac .app uses user state.
See README for tracking, recording, ZMQ, live plot and source builds.
https://github.com/pvnkmrksk/rekke
